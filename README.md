# Dashboard de Operações de Delivery | Power BI

## Sobre o projeto

Projeto de Business Intelligence desenvolvido no Power BI Desktop para analisar o desempenho operacional de um serviço de delivery.

O dashboard permite acompanhar indicadores de produtividade, faturamento, cumprimento de SLA, ruptura, cancelamentos e defeitos, apoiando a identificação de oportunidades de melhoria na operação.

## Indicadores analisados

| Indicador | Resultado |
|---|---:|
| Total de pedidos | 1.800 |
| Faturamento total | R$ 83.902,18 |
| Pedidos dentro do SLA | 61,72% |
| Pedidos fora do SLA | 689 |
| Tempo médio de separação | 17,99 minutos |
| Taxa de ruptura | 3,50% |
| Taxa de cancelamento | 4,11% |
| Taxa de defeitos | 5,33% |

## Funcionalidades

- Indicadores calculados por meio de medidas DAX.
- Análise de desempenho por loja, turno e operador.
- Gráficos comparativos de produtividade e cumprimento de SLA.
- Filtros interativos que atualizam os indicadores conforme a seleção.
- Formatação condicional para destacar indicadores operacionais.
- Alerta visual automático para taxas de defeitos iguais ou superiores a 6%.

## Tecnologias utilizadas

- Microsoft Power BI Desktop
- DAX (Data Analysis Expressions)
- Modelagem e análise de dados
- Visualização de dados
- Indicadores de desempenho (KPIs)

## Principais observações

A análise geral identificou um cumprimento de SLA de 61,72%, permitindo visualizar diferenças de desempenho entre lojas, turnos e operadores.

O dashboard também permite identificar operadores com taxas de defeitos acima do limite de referência de 6%, utilizando indicadores visuais dinâmicos.
